05 / FAQ

Quick answers.

What does Tojioka edit with?+

The public project files and presets are built for Adobe After Effects 2020. Some products also use plugins such as Magic Bullet Looks, Boris FX Sapphire and Deep Glow.

Where can I get project files and presets?+

They are sold through Tojioka’s official Payhip shop. The current catalog includes Dark CC, Bright CC, a Goku vs Saitama composition project and a free/pay-what-you-want Demon Slayer project file.

What is the Discord for?+

The server is focused on helping editors, with clips/materials, editing resources and quality/upscale help.

How can I contact Tojioka?+

For file questions or contact, use Discord @wusayy or email tojioka.contact@gmail.com.
